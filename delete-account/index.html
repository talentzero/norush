Delete your Sweet Sweet Go game account and data

Sweet Sweet Go is published by No Rush. You can request deletion even if you no longer have the Game installed.

Request deletion without the Game

Email support.norush@gmail.com with the subject Sweet Sweet Go account deletion request. Tell us that you want your Sweet Sweet Go game account and associated data deleted. If you know your in-game player ID or had connected Google Play Games or Game Center, mention that so we can help identify the correct game account. Do not send passwords, authentication codes, or payment details. We may ask for additional information to verify ownership before processing the request. You do not need to reinstall the Game to submit it.

What the request covers

For an adult cloud player, deletion covers the associated Unity Authentication game account, Unity Cloud Save progress, and global Best Distance leaderboard entry. The in-app Delete All Game Data action also clears local progress and recovery state on that device. A request made by email cannot itself erase copies stored only on a device we cannot access; the player can clear those through the Game’s Reset Local Data control or by removing the Game’s local storage.

The Game can queue a Unity Analytics data-purge request but does not receive a definitive receipt when the server purge finishes. Advertising and platform providers may handle information under their own retention rules. We will explain any data that must be retained for legal, security, or fraud-prevention reasons when responding to a request.

Deletion of the Sweet Sweet Go game account does not delete your external Google account, Google Play Games identity, Apple Account, or Game Center identity.

Delete from within the Game

When the adult cloud feature is available, open Settings and choose Delete All Game Data. This requires an internet connection and two confirmations. Reset Local Data only clears data stored on that device and does not intentionally delete the cloud account, cloud progress, or global ranking.

Read the Sweet Sweet Go Privacy Policy for more about the Game’s data practices.
